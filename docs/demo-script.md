# AI Agent Workshop 演示脚本

> 时长：2小时 | 目标受众：技术团队 | 形式：讲解+演示+动手实操

---

## 开场 (5min)

**讲师说明：** 简要介绍自己、Workshop目标和议程。强调这不是纯理论课，重点是"看得见、摸得着"的Agent能力展示。

**演示步骤：**
1. 展示议程幻灯片，说明三个Session的核心目标
2. 快速举手调查：谁用过ChatGPT？谁用过Agent类工具？

**预期效果：** 学员了解课程结构，建立期待感。

**注意事项：** 控制时间，不要展开闲聊。确保网络和演示环境提前就绪。

---

## Session 1: AI Agent vs LLM 探讨分析 (40min)

### 1.1 LLM是什么 - 对话演示 (8min)

**讲师说明：** 用ChatGPT/Claude演示纯LLM对话——输入问题，返回文本。强调LLM本质是"文本补全机器"，没有行动能力。

**演示步骤：**
1. 向LLM提问："帮我查一下今天GitHub上trending的Python项目"
2. 展示LLM只能给出通用建议，无法实际访问网络
3. 再问："帮我创建一个文件" → LLM只能输出代码，不能执行

**预期效果：** 学员直观感受到LLM的边界——能说不能做。

### 1.2 Agent是什么 - 对比演示 (8min)

**讲师说明：** 用同样的问题交给Agent（如OpenClaw/Copilot Agent），展示Agent如何调用工具完成任务。

**演示步骤：**
1. 同样的问题发给Agent，观察Agent自动调用搜索工具获取实时数据
2. 让Agent创建文件 → 实际在文件系统中生成
3. 对比两次结果，突出差异

**预期效果：** "哇，它真的做到了" —— 形成鲜明对比。

### 1.3 架构对比图讲解 (10min)

**讲师说明：** 展示架构图，讲解核心公式：**Agent = LLM + Tools + Memory + Planning**

**演示步骤：**
1. 画出LLM架构：User → LLM → Response（单轮）
2. 画出Agent架构：User → Agent(LLM + 工具调用 + 记忆 + 规划) → 多步执行 → Result
3. 逐一讲解四个组件的作用：
   - **LLM**：大脑，负责理解和推理
   - **Tools**：手脚，负责执行（搜索、代码、API调用）
   - **Memory**：记忆，短期对话上下文 + 长期知识库
   - **Planning**：规划，将复杂任务拆解为步骤

**预期效果：** 学员建立清晰的Agent心智模型。

### 1.4 讨论：什么时候用Agent vs 直接用LLM (14min)

**讲师说明：** 引导互动讨论，给出决策框架。

| 场景 | 推荐 | 原因 |
|------|------|------|
| 写一封邮件 | LLM | 单轮文本生成，无需工具 |
| 调研竞品并生成报告 | Agent | 需要搜索、整理、多步骤 |
| 翻译一段话 | LLM | 简单转换任务 |
| 自动review代码并提PR | Agent | 需要读代码、分析、写评论 |

**注意事项：** 鼓励学员举自己工作中的例子，增加参与感。

## Session 2: Agent日常工作使用场景展示 (40min)

### 场景1: 代码审查与开发 (10min)

**讲师说明：** 展示Agent自动review PR的完整流程。

**演示步骤：**
1. 提交一个包含故意bug的PR到测试仓库
2. 触发Agent自动审查，观察它识别问题并留下评论
3. 展示Agent提出修复建议的diff

**预期效果：** 学员看到Agent能发现真实代码问题并给出具体修复方案。

**注意事项：** 提前准备好测试仓库和PR，避免现场等待CI。

### 场景2: 研究与分析 (10min)

**讲师说明：** 展示Agent完成"搜索→分析→生成报告"的完整链路。

**演示步骤：**
1. 给Agent任务："调研2024年主流AI Agent框架，对比LangChain、CrewAI、AutoGen，生成Markdown报告"
2. 观察Agent逐步搜索、整理信息、生成结构化报告
3. 展示最终输出的报告质量

**预期效果：** 原本需要2小时的调研工作，Agent在几分钟内完成。

### 场景3: 日常自动化 (10min)

**讲师说明：** 展示Agent处理定时任务和消息通知的能力。

**演示步骤：**
1. 展示通过WeChat向Agent发送指令："每天早上9点提醒我查看GitHub通知"
2. 展示Agent整合日报：自动汇总昨日PR、Issue、部署状态
3. 演示Agent发送格式化的通知消息

**预期效果：** 学员意识到Agent可以成为个人工作助手。

### 场景4: 多Agent协作 (10min)

**讲师说明：** 展示主Agent将任务拆分并分发给子Agent并行处理。

**演示步骤：**
1. 给主Agent一个复合任务："分析这个项目的代码质量、安全漏洞、文档完整性"
2. 观察主Agent拆分为3个子任务，分别由专门的子Agent处理
3. 展示最终汇总结果

**预期效果：** 理解多Agent架构的价值——并行、专业化、可扩展。

**注意事项：** 如果网络慢导致等待，可切换到预录视频。

## Session 3: 动手安装OpenClaw (40min)

### 3.1 环境准备 (5min)

**讲师说明：** 确认学员环境满足要求。

**演示步骤：**
1. 检查Node.js版本：`node -v` (要求 ≥18)
2. 检查Git：`git --version`
3. 确认有GitHub账号且已配置SSH key
4. 确认有GitHub Copilot订阅（或试用）

**注意事项：** 提前发安装指南，减少现场等待。准备便携热点以防WiFi不稳。

### 3.2 安装步骤 (10min)

**演示步骤：**
```bash
# 克隆项目
git clone https://github.com/anthropics/openclaw.git
cd openclaw

# 安装依赖
npm install

# 复制配置文件
cp .env.example .env
```

**预期效果：** 全员完成安装，无报错。

**注意事项：** 常见问题提前准备FAQ，安排助教巡场协助。

### 3.3 配置GitHub Copilot (10min)

**演示步骤：**
1. 在`.env`中配置Copilot API相关参数
2. 配置模型选择（推荐Claude Sonnet）
3. 运行验证命令确认连接成功

**预期效果：** Agent能成功调用LLM后端。

### 3.4 连接WeChat (10min)

**演示步骤：**
1. 配置WeChat接入参数
2. 启动服务：`npm start`
3. 扫码登录WeChat
4. 在微信中发送测试消息

**预期效果：** 在微信中收到Agent的回复，完成端到端验证。

**注意事项：** WeChat登录可能触发安全验证，提前告知学员。部分企业网络可能有限制。

### 3.5 测试对话 (5min)

**演示步骤：**
1. 发送简单问题测试基本对话
2. 发送需要工具调用的任务（如"帮我搜索XXX"）
3. 确认工具调用正常工作

**预期效果：** 学员拥有一个可用的私人AI Agent！🎉
